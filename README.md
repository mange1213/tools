TOOL APP INSTALL REPAIR FILES

These files are arranged at the ZIP root so they can be uploaded directly into the ROOT of the GitHub Pages repository (the same folder that contains index.html).

IMPORTANT: Before replacing/uploading anything, download a backup from the working app. Do not delete the current site or clear browser data.

To publish: extract this ZIP, then upload the files inside it (not the enclosing folder) into the repository root. Keep index.html and all existing app assets. If GitHub asks to replace existing files, only proceed after a backup. Commit changes, wait for Pages to publish, then test https://YOUR-SITE/manifest.webmanifest and https://YOUR-SITE/icon-192.png.

This package corrects the manifest configuration and cache version, but it has not been deployed to or tested against your live GitHub Pages site.
